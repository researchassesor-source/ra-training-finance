# Decisión de nomenclatura

| Variante encontrada | Fuente | Tratamiento |
|---|---|---|
| `R.A Training` | Sitio institucional | Se reconoce como variante pública de la marca. |
| `RA-Training` | Sitio institucional y certificado histórico | Se conserva en textos históricos y roles impresos. |
| `Research Assessor & Training` | Metadatos/certificado | Se conserva dentro del arte del certificado. |
| `R.A. Training` | Aplicación Finance existente | Marca matriz elegida para la interfaz. |
| `Finanzas` | Sidebar e informes existentes | Se reemplaza visualmente por `Finance`; no se alteran datos. |
| `R.A. Training Finance` | Repositorio, API y documentación | Nombre completo elegido. |

## Nombre aplicado

- Marca: **R.A. Training**
- Aplicación: **Finance**
- Nombre completo: **R.A. Training Finance**
- Subtítulo: **Sistema de gestión financiera y certificación**

La decisión prioriza la marca publicada y la denominación técnica ya establecida. No se encontraron `Resources Training`, `Everest Training` ni `R.A. Training Finances` en la base revisada.

## Exclusiones

No se cambian nombres propios, razón social, RUC, certificados históricos, textos legales ni denominaciones ya impresas dentro de imágenes entregadas.
