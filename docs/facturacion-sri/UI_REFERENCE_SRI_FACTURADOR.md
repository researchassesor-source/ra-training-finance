# Referencia funcional del Facturador SRI

Se tomó como referencia la secuencia funcional pública del Facturador SRI: perfil/firma, productos/servicios y emisión. No se copiaron código, estilos, imágenes ni un diseño pixel-perfect.

La UI de R.A. Training mantiene sidebar, colores, tipografía, botones y tarjetas. Nueva factura se divide en:

1. Datos de emisión.
2. Adquirente.
3. Detalle multilínea.
4. Formas de pago múltiples y descriptivas.
5. Campos adicionales.
6. Totales.
7. Acciones y bloqueadores.

El resumen es sticky en escritorio y accesible en móvil. Los detalles técnicos se concentran en configuración/auditoría. Siempre se muestra ambiente local, sin validez y no conectado al SRI.
