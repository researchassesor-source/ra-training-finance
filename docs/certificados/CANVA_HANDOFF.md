## Requisitos para una implementación futura

1. Exportación aprobada en PNG o PDF con dimensiones y sangrado definidos.
2. Identificador y versión de cada modelo.
3. Reglas sobre firmas, aval, textos legales y modalidad.
4. Coordenadas documentadas de cada campo dinámico.
5. Pruebas con nombres y cursos largos, QR e impresión.
6. Conservación de cada versión histórica para que una reemisión sea trazable.

No se deben inventar firmas, entidades avaladoras ni textos institucionales al preparar modelos futuros.
