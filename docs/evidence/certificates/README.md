Fecha: 27 de julio de 2026
Datos: las capturas de evidencia están redactadas y utilizan textos ficticios.

## Cambio aprobado

Se sustituyó la plantilla rasterizada por la referencia entregada por gerencia, conservando exactamente 1440 × 960 px. El archivo aplicado tiene el mismo SHA-256 que la referencia recibida.

Únicamente desaparecen:

- la línea naranja horizontal bajo el nombre del participante;
- las dos líneas naranjas laterales del nombre del curso.

Se conservan los bordes, el logotipo, los dos espacios de firma, las firmas existentes, el sello, el recuadro de verificación, la orientación, los textos institucionales y el QR dinámico generado por inscripción.
